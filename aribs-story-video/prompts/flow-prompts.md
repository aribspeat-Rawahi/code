# ARIBS Palm-to-Peat — AI video prompts (Google Flow / Veo, OpenArt, Kling, Runway)

**Mode:** image → video, with the approved scene still as the start frame (Flow: *Frames to Video*;
OpenArt / Kling / Runway: *Image to Video*). Start frames, 16:9, 1920x1080: `prompts/frames/sceneN-16x9.jpg`.
**Length:** 8 s each. **Aspect:** 16:9. The storyboard-to-video skill crops a square from it for both the
16:9 and 9:16 films, so keep the action in the middle of the frame.

Paste the **style lock** and **character line** at the end of every prompt (they are already included below).
After generating: save as `public/remake/clips/sceneN.mp4`, set `"video"` on that scene in the storyboard,
and render with the storyboard-to-video skill (voiceover, captions, logo text and music are added there).
